# Recon Drone — Embedded & Robotics

Recon Drone is a hobby embedded-systems and robotics project to design and build a compact, two-wheeled ground reconnaissance robot inspired by the standard drone in *Tom Clancy's Rainbow Six Siege*. The planned system supports wireless manual control, live first-person-view (FPV) video, and controlled jumping in an advanced development phase.

Project requirements, design decisions, milestones, and progress are maintained in the [Project Master Document](docs/00_PROJECT_MASTER.md). Repository working conventions are defined in [AGENTS.md](AGENTS.md).
